Para que tu agente atienda mensajes de whatsapp por ti, deberás seguir las siguientes instrucciones:

  1. Genera un código QR
  2. En tu smartphone, abre la aplicación de whatsapp
  3. Toca Menú o Configuración y selecciona WhatsApp Web
  4. Cuando se active la cámara, apunta tu teléfono hacia esta pantalla para escanear el código. Al hacerlo, agente smart responderá por ti.

En caso de que desees detener las respuestas automáticas del agente, haz lo siguiente:

  1. En tu smartphone, abre la aplicación de whatsapp
  2. Toca Menú o Configuración y selecciona WhatsApp Web
  3. Elige la sesión creada con agente smart y a continuación "Cerrar Sesión"
